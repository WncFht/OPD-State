# OPD 访问测度研究工作记录

## 目标与验证边界

目标是解释三篇指定论文中的状态覆盖、离线缓存与 OPD 切换平台现象，推导 sampled-token 更新的保证条件，并设计能区分 prefix 分布与 action 分布作用的实验。成品写给熟悉语言模型训练、希望独立核验推导的研究者。

成功条件：三篇论文的目标和关键实验证据有本地来源定位；条件 KL、序列 KL 与任务正确率的关系有完整推导；至少一个精确可枚举反例核验不保证改进的结论；混合 rollout 的定义、测度、修正与可证伪实验设计明确。

否决条件：如果精确期望下局部更新总能下降序列 KL，则不能把缺少未来项当作失效机制；如果覆盖充分且教师可实现时不同状态权重仍改变零损失解，则需修正对访问测度的论断。数值实验只检验构造和公式，不用于宣布真实 LLM 的主导失效原因。

可变选择：优先使用 CPU 上可枚举的树形策略与有限参数模型；只有数学核验不足才增加 LLM 实验。GPU 实验限物理编号 0–3，不使用 4 及以后设备。成品与过程记录分开。

## 来源与决策

- 本地三篇论文是中文 LaTeX，含少量明显翻译错误；以公式、表格、图与上下文交叉核验，引用保留原英文论文题名。
- 2610.11291 的 overlap 方向是低 overlap 更易出现 OPD 劣化；同一准确率平台不等于同一策略，更不构成全局起点无关定理。
- 2609.04172 的 one-shot 是单个 query 上持续采样；其固定 64 条轨迹实验仍需数百步，与“单次 rollout 很快吸收完毕”不同。
- 将行为策略、prefix 访问测度、用于梯度估计的 action 采样分布分开；离线 sampled-token 不加重要性修正会改变条件目标，不能将所有差异归于 state。
- MirrorOPD 仅作只读参考。当前 `on_policy` 的中心化信号及缓存生命周期与论文裸优势不完全相同，真实复现前必须单独控制。
- 根目录的 `docs/2026-10-13-环境与项目入口.md` 与 `/root/.agents/AGENTS.md` 在本环境中不存在；已读取用户给出的全局规则、当前工作区 AGENTS.md 和 `docs/2026-10-17-本机OPD环境与使用说明.md`。不涉及家目录配置或远程环境变更。
