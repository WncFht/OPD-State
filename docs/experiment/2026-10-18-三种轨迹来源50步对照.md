# 三种轨迹来源的 50 步对照

## 结论与范围

三个轨迹来源均已完成 50 步训练和完整三基准 eval16。在线 student 的 macro mean@16 为 64.8396%，Semi-OPD 为 64.5944%，teacher 轨迹为 62.5208%。在线与 Semi 相差 0.245 个百分点，其成对题目 bootstrap 区间包含零；当前数据不能确认两者在该预算下存在稳定差异。teacher 轨迹相对在线组低 2.319 个百分点，题目重采样区间为 [-4.055, -0.755] 个百分点。

以下全部是训练后 student 的成绩。三个方法均从相同 student 初始化独立训练，监督 teacher 始终冻结。teacher 轨迹组由 teacher 生成训练响应，更新的仍然是 student。

目前只有每组第 50 步的一个验证预算点，不能判断渐近收敛点是否不同，也不能确认三组已收敛。后续继续运行 λ=0.5 Fusion 50 步，以及每 50 步完整验证的长时 Semi-OPD。

## 三种流程与共同设置

| 轨迹来源     | 训练响应的生成者                   | 每步更新的模型 |
| ------------ | ---------------------------------- | -------------- |
| 在线 student | 当前 student，每步重新生成         | 当前 student   |
| teacher 轨迹 | 冻结 teacher，预生成一次缓存       | 当前 student   |
| Semi-OPD     | 初始 student，训练前预生成一次缓存 | 当前 student   |

teacher 为 `JustRL-DeepSeek-1.5B`，student 初始化为 `DeepSeek-R1-Distill-Qwen-1.5B`。每步重算当前 student 和冻结 teacher 在实际轨迹上的 token log-probability，使用原 OPD 的 sampled-token 更新，不将缓存生成时的旧 student 概率作为 PPO 锚点，不使用行为重要性修正。

三个来源消费完全相同的 50 个 batch，每批 64 条，共 3,200 条 DAPO 记录。训练响应 cap 4,096、temperature/top-p 均为 1、top-k 不截断、repetition penalty 为 1。学习率 $10^{-6}$，恒定学习率且无 warmup，每步一个 PPO epoch，梯度按有效 token 平均。只在第 50 步验证，不保存模型 checkpoint，GPU 为物理 0–3。完整流程、数学语义和可复现入口见[统一协议](2026-10-18-三基准评测与轨迹来源实验.md)。

## 完整 eval16 成绩

MATH-500 为 500 题，AMC23 为 40 题，AIME25 为 30 题，每题生成 16 个响应，共 9,120 条。验证 temperature 0.7、top-p 0.9、响应 cap 31,744。下表单位均为百分比；macro 按三个基准等权，micro 按 570 题等权。

| 轨迹来源     | MATH-500 mean@16 | AMC23 mean@16 | AIME25 mean@16 | macro mean@16 | micro mean@16 |
| ------------ | ---------------: | ------------: | -------------: | ------------: | ------------: |
| 在线 student |            86.24 |         80.16 |          28.12 |         64.84 |         82.75 |
| teacher 轨迹 |            85.38 |         75.31 |          26.88 |         62.52 |         81.59 |
| Semi-OPD     |            86.70 |         78.75 |          28.33 |         64.59 |         83.07 |

在线组的 macro 均值最高，Semi 的 micro 均值最高。两种汇总对题目权重的定义不同，不能混用。MATH-500 的 500 题使 micro 更接近该基准的变化。

| 轨迹来源     | MATH-500 pass@16 | AMC23 pass@16 | AIME25 pass@16 | macro pass@16 | micro pass@16 |
| ------------ | ---------------: | ------------: | -------------: | ------------: | ------------: |
| 在线 student |            95.60 |         95.00 |          50.00 |         80.20 |         93.16 |
| teacher 轨迹 |            96.20 |         95.00 |          53.33 |         81.51 |         93.86 |
| Semi-OPD     |            96.40 |         95.00 |          46.67 |         79.36 |         93.68 |

teacher 轨迹组的平均正确率最低，但 macro pass@16 最高。AIME25 的至少一次正确题数为 teacher 16/30、在线 15/30、Semi 14/30。平均正确率与有限次采样的题目覆盖比例给出了不同排序，当前不存在覆盖全部这些指标的单一优胜组。

mean@16 等于标准 pass@1；标准 pass@k 使用无放回估计。全部 pass@1/2/4/8/16 和未舍入指标保存在[比较数据](results/2026-10-18-three-source-comparison/analysis.json)及其 `scores.csv`，原生 veRL 的 bootstrap best/maj 指标也保留在各运行日志中。

区间按基准分层、成对重采样相同题目的 mean@16 差值，5,000 次、seed 42。下表差值均为“该组减在线 student”，单位为百分点。

| teacher | AMC23    |       -4.844 |            [-9.219, -0.938] |

Semi 相对在线组的全部列示区间均包含零。teacher 相对在线组在 macro、micro、MATH-500、AMC23 的题目重采样区间不含零，AIME25 的区间包含零。这些区间描述对题目选择的敏感性，不覆盖训练随机种子方差，也没有进行多重比较校正；它们不是跨训练 seed 的算法优劣证明。

轨迹来源同时改变 prefix、采样 action、响应长度和生成内容，不能只凭这三组成绩把差异归因于 prefix 访问测度。这里验证的是给定实现和 50 步预算下的来源对照。

## 收敛判断

| 来源         | 末步 actor loss | 末步梯度范数 | 末步 log-ratio RMS |
| ------------ | --------------: | -----------: | -----------------: |
| 在线 student |        0.054435 |     0.572402 |           0.371102 |
| teacher 轨迹 |       -0.046815 |     0.519051 |           0.296459 |
| Semi-OPD     |        0.092669 |     0.803625 |           0.414405 |

三个组都只有一个验证点，没有足够证据识别准确率平台。梯度与采样残差仍非零，但非零的 batch 梯度本身也不能证明期望梯度尚未收敛。各组残差来自不同轨迹分布，不能直接横向当作同一分布上的条件 KL；teacher 组的负 surrogate loss 也不等于负 KL。

后续长时 Semi-OPD 反复使用同一缓存，每 50 步覆盖同一批固定轨迹，使跨窗口比较具有共同数据分布。从 300 步起检查最后连续四个验证点的 macro mean@16 极差、50 步窗口的 token 加权 RMS 与平均梯度范数。首轮最多 800 步；达到经验平台时在验证后正常停止，预算耗尽仍未满足时明确保留证据不足的结论。此停止条件预先固定，详见统一协议。
