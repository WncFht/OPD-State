# Logit 融合 λ=0.5 的 50 步结果

## 结论与范围

当前 student 与冻结 teacher 的共享 prefix logit 融合已完成 50 步 student 更新及三基准完整 eval16。最终 student 的 mean@16 为 MATH-500 86.275%、AMC23 78.90625%、AIME25 27.2917%，macro 为 64.1576%。相对在线 student 的 macro 差值为 -0.682 个百分点，成对题目 bootstrap 95% 区间为 [-2.149, 0.681] 个百分点；当前单 seed、50 步预算未显示稳定的平均正确率增益。

训练进程退出码为 0，W&B g5m60gys 为 finished，远端保存完整 50 步和全部精确指标。[^wandb-fusion-50] 原始 9,120 条响应经独立重算，与训练日志和远端摘要逐项一致。

实现已通过数学端点、共享 prefix、EOS/padding、缓存重置、权重版本、冻结教师、FP32 attention 对照、独占 GPU 性能、两步完整训练及此次 50 步正式训练。工程验收通过；任务准确率的比较仍按实际观测和区间解读。

## 实际执行的训练流程

student 初始化为 `DeepSeek-R1-Distill-Qwen-1.5B`，teacher 为冻结的 `JustRL-DeepSeek-1.5B`。每步将最新 student 参数同步到融合推理副本，在相同 prefix 上计算两组 logits，以

$$
\mu_\theta(a\mid s)=\operatorname{softmax}\!\left(0.5z_{\pi_\theta}(s)+0.5z_q(s)\right)_a
$$

采样下一个 token，再将同一个 token 送入两模型各自的 KV cache。训练 temperature 为 1、top-p 为 1、top-k 不截断。融合策略的 log-probability 只作诊断；原 OPD 监督继续使用冻结 teacher 的 log-probability 与当前 student 的 log-probability，只更新 student。

全部 50 步的生成版本严格为 0–49，即第 $t$ 步 rollout 使用第 $t-1$ 次更新后的 student；lambda 始终为 0.5，loss、梯度和行为 log-probability 全部有限。按四个 DP worker 汇总的生成 token 数与训练响应 mask 完全一致，共 12,436,547 个有效响应 token。检查结果保存在[版本与长度不变量](results/2026-10-18-math-fusion-lambda05-50steps-eval16-20261018-065746/fusion-invariants.json)。

最终验证走原生 student-only vLLM 路径，使用更新后的 student 独立生成答案，不用融合策略生成验证响应。teacher 未参与参数更新。

## 性能与训练残差

训练 batch 64、每题一个响应、训练 cap 4,096、prompt cap 1,024、学习率 $10^{-6}$、恒定学习率且无 warmup、每步一个 PPO epoch，GPU 为物理 0–3。第 50 步执行唯一一次正式验证，没有保存模型 checkpoint。

生成计时合计 2,450.6 秒，训练步骤合计 2,999.0 秒，最终验证 5,907.6 秒。在线单模型组的训练步骤合计为 2,348.7 秒；融合使用双模型生成，正式训练总耗时仍高于在线单模型组。独占 H800 的短序列微基准中，图与 FlashAttention KV 路径相对未优化的双模型 DynamicCache eager 在 batch 16 下快 3.73 倍，不能把该数字当作整段训练相对原生 vLLM 的加速比。

末步 actor loss 为 -0.00264627，梯度范数为 0.529680，log-ratio RMS 为 0.314388。前十步 RMS 均值为 0.427681，后十步为 0.324119。融合分布上的 signed surrogate 均值接近零不等于对齐误差为零；单个验证预算点也不能证明收敛。当前首轮结果支持实现可运行，不支持平均准确率稳定优于在线 student 的结论。
