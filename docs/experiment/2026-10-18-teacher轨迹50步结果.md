# Teacher 轨迹训练 student 的 50 步结果

## 结果与适用范围

固定 teacher 轨迹组已完成 50 步 student 更新。MATH-500、AMC23、AIME25 的 mean@16 分别为 85.375%、75.3125%、26.875%，三基准等权 macro mean@16 为 62.5208%。原始 9,120 条响应经独立重算，与训练日志的全部精确指标一致。训练进程退出码为 0，W&B 状态为 finished，远端保存了完整 50 步训练记录。[^wandb-teacher-50]

该结果是 teacher 生成轨迹之后训练所得 student 的成绩。生成与监督教师为 `JustRL-DeepSeek-1.5B`，可训练 student 为 `DeepSeek-R1-Distill-Qwen-1.5B`。teacher 参数设为 `requires_grad=False`，每步重算当前 student 的 log-probability，以原教师的 token 信号更新 student，最终验证由 student 独立生成。

目前还没有同一 eval16 协议下的在线 student、Semi-OPD 和 Fusion 结果，不能据此判断来源之间的准确率优劣。[旧 greedy 基线](2026-10-18-math50步基线结果.md)采用不同采样和长度预算，不参与数值对照。

## 训练与计算成本

训练消费配对 schedule 的前 50 个 batch，每批 64 条，共 3,200 条轨迹。teacher 预生成轨迹的训练响应上限为 4,096 token，temperature/top-p 均为 1；缓存包含 12,493,768 个响应 token。50 步均命中缓存，最终读取计数为 3,200，无在线补采样。学习率为 $10^{-6}$，每步一个 PPO epoch，梯度按有效 token 平均。

teacher 缓存生成耗时 545.4 秒，训练步骤计时合计 409.6 秒，最终验证耗时 6,068.4 秒，约 101.1 分钟。三项计时范围分别来自生成器 manifest、训练日志和最终 testing 计时，不包含相同的启动与模型加载范围，不能直接相加当作严格的端到端总时间。固定轨迹的训练耗时也不能省略预生成成本后与在线组比较。

仅第 50 步验证，没有训练前或中间验证，没有保存模型 checkpoint。GPU 仅使用物理 0–3，W&B project 为 OPD-State。

## 训练残差与后续判断

末步 actor loss 为 -0.0468153，梯度范数为 0.519051，log-ratio RMS 为 0.296459。前十步 RMS 均值为 0.438914，最后十步均值为 0.309305。梯度和残差仍非零，且只有一个验证预算点，当前证据不足以判断已收敛。

teacher 来源下的 sampled-token surrogate loss 可以为负，其符号不等于条件 KL 的符号。来源对照应在相同评测协议下比较 student 的任务成绩，长时组再按预先固定的[经验平台判据](2026-10-18-三基准评测与轨迹来源实验.md#配对比较与经验平台判据)同时检查准确率和固定缓存残差。
