# 多来源 rollout 的条件蒸馏算法

更新时间：2026-10-19。本文定义 sampled token、top-k 与 full-vocab 如何在不同 rollout 来源上优化同一个条件 reverse KL，说明前向、缓存、梯度和归约的职责。性能实现与实测见[完整词表蒸馏优化与四卡实测](2026-10-19-完整词表蒸馏优化与四卡实测.md)。

与 MirrorOPD 的现状对照及公共积分接口见[两仓动作积分现状与统一方案](2026-10-19-两仓动作积分现状与统一方案.md)。该方案保留 Mirror 的 on_policy、MDPO、BPO 目标，不能将它们全部替换为本文的普通 reverse KL。

实现状态：现有原生多来源训练仍使用生成 token 的 log-ratio reward，未统一为本文的条件目标。sampled token 重新采样、跨来源的无偏 top-k 属于待接入方案；full-vocab 有独立 GPU 训练原型，尚未接入原生 verl trainer。以下“正确”均相对于本文明确的条件 reverse KL 目标，不表示其他目标不能研究。

## 统一目标与 rollout 的职责

第 k 轮开始时，当前 student 为 $p_k=p_{\theta_k}$，冻结 teacher 为 q，轨迹生成策略为 $\mu_k$。先生成完整响应，再抽取有效预测位置：

$$
y\sim\mu_k(\cdot\mid x),\qquad s_t=(x,y_{<t}),\qquad a_t^{\rm roll}=y_t.
$$

初始 student、teacher、fusion、分段和 batch 混合均可充当 $\mu_k$。它们决定访问哪些前缀，以及 EOS、响应长度和有效位置集合；训练目标中的 teacher 始终为 q，融合策略不会自动成为 teacher。

设本轮有效位置集合为 $\mathcal S_k$，大小为 $N_k$。对已收集位置使用统一的 pooled token mean：

$$
L_k(\theta)=\frac{1}{N_k}\sum_{s\in\mathcal S_k}D_s(\theta),\qquad
D_s(\theta)=\sum_{a\in V}p_\theta(a\mid s)\log\frac{p_\theta(a\mid s)}{q(a\mid s)}.
$$

一次更新中，$\mathcal S_k$ 和 $N_k$ 固定，不对轨迹生成求导。原响应始终作为 teacher forcing 的输入；另采的训练 action 不替换响应，也不改变后续前缀。改变来源允许改变外层状态测度，三种估计方式统一内层动作目标。

这定义的是已收集前缀上的条件 KL 更新。当 $\mu_k$ 来自当前 student 时，它仍不包含对状态访问测度求导产生的未来状态项，不能直接称为完整 sequence KL 梯度。详细区分见[局部梯度与长度归约](../occupancy/2026-10-18-局部梯度与长度归约.md)。有限 batch 的 token 比率归约也不自动等于总体访问测度下严格无偏的估计；本文的 action 无偏性以已固定的位置为条件。

## student 是否需要重新前向

**在当前生成/训练分离架构中，所有来源均需要一次 student 带梯度的 teacher-forcing 前向。**即使轨迹刚由当前 student 生成，vLLM 的推理 logits/KV 也没有训练所需的 backbone 计算图。生成时记录的 log-prob、hidden 或 KV 不能直接使全部 student 参数获得梯度。

| rollout 来源      | 生成阶段执行的模型         | 蒸馏阶段需要的分布                                             |
| ----------------- | -------------------------- | -------------------------------------------------------------- |
| 当前 student      | 当前 student 的推理副本    | 当前 student 在全部原前缀上的带梯度分布，以及冻结 q            |
| 初始 student      | 冻结的初始 student         | 当前 student 与冻结 q；初始 student 的概率不替代当前 student   |
| teacher           | teacher 的推理副本         | 当前 student 与冻结 q；teacher 生成的 token 不直接成为蒸馏标签 |
| logit fusion      | base 与 teacher 的推理副本 | 当前 student 与冻结 q；融合 logits 不能替代任一完整分布        |
| 分段或 batch 混合 | 按位置或轨迹路由到来源模型 | 每条完整原轨迹仍交给当前 student 与冻结 q 评分                 |

对整条已知序列的一次因果前向可以同时取得各位置的条件分布，不是对每个前缀单独运行一次完整模型，也不是再生成一条响应。预测 $y_t$ 使用它之前位置的 hidden，不能读入 $y_t$ 后再计算监督它的概率。

teacher 同样需要对这些原前缀给出 q，但可以无梯度运行。如果生成端已经准确导出同一前缀、同一 teacher 版本的最终 hidden，以及可匹配的 head、温度与词表语义，理论上可以复用，避免再次 teacher backbone 前向。现有原生生成输出没有这套缓存合同，不能默认已实现；推理端仅保存 sampled-token log-prob 不足以恢复完整 q。

### 前向相似，训练职责不对称

| 项目                 | student                                                                       | teacher                                     |
| -------------------- | ----------------------------------------------------------------------------- | ------------------------------------------- |
| 条件输入             | 原始 rollout 的同一前缀                                                       | 原始 rollout 的同一前缀                     |
| backbone/head        | 计算当前 $p_\theta$                                                           | 计算冻结 q                                  |
| 反向图               | 需要；可用激活重计算降低保存量                                                | 不需要，使用 no-grad                        |
| 参数梯度与 optimizer | 更新全部指定的训练参数                                                        | 无梯度、无 optimizer 更新                   |
| hidden 缓存          | 本次训练 hidden 必须能将梯度传回 backbone；更新后不能把旧 hidden 当作当前分布 | 同一 prefix/模型版本下可长期复用最终 hidden |
| 输出头               | 可训练，分块累计 head 梯度                                                    | 冻结，仅用于重建 q                          |
| reverse KL 的权重    | $p_\theta$ 是词表积分权重                                                     | q 提供 log-prob 目标                        |

所以既有计算图不对称，也有目标方向不对称：交换两者会得到 $D_{\rm KL}(q\Vert p_\theta)$，是另一个目标。在分块 full-vocab 原型中，teacher 先无梯度前向；student 随后带梯度前向；块内计算双方 head，但只返回 student hidden/head 的梯度。

自定义 autograd 在内部临时 detach student hidden 以计算局部梯度，并不意味着冻结 backbone：它必须在 backward 中把 $\partial L/\partial h_s$ 返回到原 student hidden 的输入边。若仅缓存 detached student hidden 后训练 head，就变成只训练输出层，不能视为同一算法。

## 三种估计方式共有的梯度公式

固定状态 s，省略条件记号，定义

$$
e_a=\log p_a-\log q_a,\qquad r_a=-e_a,\qquad
u_a=\nabla_\theta\log p_a.
$$

由 $\sum_a p_a=1$ 得 $\sum_a p_au_a=0$，因此

$$
\nabla_\theta D_s
=\sum_a p_a(e_a+1)u_a
=\sum_a p_ae_au_a.
$$

后续 score surrogate 中 $\operatorname{sg}$ 表示停止梯度。它的显示数值通常不是 KL；应另行报告 KL 数值或其估计。下面的冻结系数 surrogate 在 $\theta=\theta_k$ 与当前条件 KL 梯度对应。若执行多次参数更新，应重新取得当前 student 概率、系数及相应样本；固定旧 reward、PPO clipping 或旧重要性比率不会使后续每一步继续成为精确当前 KL 梯度。

### Sampled token：按当前 student 采训练 action

每个固定位置 s 上，独立于原生成 action 另采 $\tilde a\sim p_k(\cdot\mid s)$。这里独立是指重新进行条件采样，而非要求不同位置的模型分布独立。

1. 保留原响应作为因果输入。teacher 无梯度前向，取得可重建 q 的最终 hidden；student 带梯度前向，取得当前位置 logits。
2. 从完整归一化的 $p_k(\cdot\mid s)$ 采一个训练 action $\tilde a$，采样操作停止梯度。该 action 不接回原轨迹。
3. 在同一前缀上取得 $\log p_k(\tilde a\mid s)$ 与 $\log q(\tilde a\mid s)$，构造停止梯度的 reward。
4. 对下式求梯度，按全部有效位置归约，再更新 student：

$$
r_k(s,\tilde a)=\log q(\tilde a\mid s)-\log p_k(\tilde a\mid s),
\qquad
\ell_{\rm sample}(\theta;s)=-\operatorname{sg}[r_k(s,\tilde a)]\log p_\theta(\tilde a\mid s).
$$

它在本轮参数处满足

$$
\mathbb E_{\tilde a\sim p_k}\!\left[\nabla_\theta\ell_{\rm sample}(\theta_k;s)\right]
=\sum_a p_k(a)e_k(a)u_k(a)
=\nabla_\theta D_s(\theta_k).
$$

同一组 student logits 可以一份 detach 后用于采样和系数，一份保留计算图用于 gather 的 log-prob；数学上不要求额外一次 student 评分前向。当前“评分 worker 先返回、训练 worker 随后更新”的旧流水线会执行两次 student 前向，是执行布局的代价。

若复用 $a^{\rm roll}\sim b(\cdot\mid s)$，须在支持覆盖和真实行为概率已知时改用

$$
\ell_{\rm IS}(\theta;s)
=\operatorname{sg}\!\left[\frac{p_k(a^{\rm roll}\mid s)}{b(a^{\rm roll}\mid s)}e_k(s,a^{\rm roll})\right]
\log p_\theta(a^{\rm roll}\mid s).
$$

当前 student、同版本且实际采样分布一致时，b=p_k，可直接复用生成 action。teacher、初始 student、fusion 等通常不满足该条件；分段/batch 来源需要正确的来源条件行为概率。硬截断造成的缺失支持不能靠重要性权重恢复。action 修正只统一条件梯度，不把状态分布也修正成当前 student 分布。

### Top-k：精确枚举头部，明确尾部如何处理

取冻结候选集 $H_k(s)=\operatorname{TopK}_a p_k(a\mid s)$，其补集为 T。候选的 $p_a,q_a$ 始终使用完整词表归一化，不在 H 内再次归一化。

**只保留头部的 score 近似**是

$$
\ell_H(\theta;s)=\sum_{a\in H}\operatorname{sg}[p_k(a)e_k(a)]\log p_\theta(a),
\qquad
g_H=\sum_{a\in H}p_k(a)e_k(a)u_k(a).
$$

它省去尾部贡献，通常有偏。候选集由 teacher 选取也可定义，但不能因此把 reverse KL 中的 student 权重换成 teacher 权重。若将权重改为 $p_a/\sum_{b\in H}p_b$，还会额外改变每个状态的梯度尺度。

直接对截断标量 $D_H(\theta)=\sum_{a\in H}p_\theta(a)e_\theta(a)$ 求导，则得到 $\sum_{a\in H}p_a(e_a+1)u_a$。由于只枚举部分词表，$\sum_{a\in H}p_au_a$ 一般非零；它与上述“完整梯度的头部”不同。把双方都在 H 内归一化后计算 KL 又是第三个目标，只对齐集合内部的比例。配置名“top-k KL”必须说明是哪一种。

**用于同目标比较的无偏 top-k＋tail 算法**如下：

1. 对同一组原前缀执行 teacher 无梯度前向和 student 带梯度前向，固定当前候选 ID 集合 H。
2. 在完整词表归一化下，gather 头部的 student/teacher log-prob，得到停止梯度的 $p_ke_k$ 系数。
3. 另采 $\tilde a\sim p_k(\cdot\mid s)$。若采样落在 H 内，尾部贡献记零；否则 gather 该 action 的 log-prob 并构造停止梯度的 $e_k(\tilde a)$。
4. 用以下 score surrogate 反向，按有效位置归约，更新 student：

$$
\ell_{H+T}(\theta;s)
=\sum_{a\in H}\operatorname{sg}[p_k(a)e_k(a)]\log p_\theta(a)
+\operatorname{sg}[\mathbf1_{\tilde a\in T}e_k(\tilde a)]\log p_\theta(\tilde a).
$$

尾部项的期望为 $\sum_{a\in T}p_k(a)e_k(a)u_k(a)$，加上头部正好得到完整梯度。这里从完整 p 采样，因此指示项外不再乘尾部概率。另一种合法实现是从条件尾部分布 $p_k(\cdot\mid T,s)$ 采样，然后乘尾部质量 $\tau_k=\sum_{a\in T}p_k(a\mid s)$；两种采样方式的系数不能混用。尾部质量为零时直接省略尾部。

理论上 K=0 退化为 sampled token，K=V 时尾部消失，恢复完整词表的冻结 score 梯度。已有`opd_topk_tail.py`实现了同类 head/tail 系数，但当前使用原 responses 作为尾部样本，不能不改数据流就覆盖任意 rollout 来源。

### Full-vocab：直接反向传播完整条件 KL

1. teacher 对原轨迹做无梯度 backbone 前向，只保留有效预测位置的最终 hidden；已有同版本缓存时可复用。
2. 当前 student 对同一原轨迹做带梯度 backbone 前向，保留计算图或采用激活重计算。
3. 按有效位置分块，双方 head 在该块投影完整有效词表，以 FP32 计算 log-softmax 和 KL。
4. 对下式直接求梯度。teacher 分支停止梯度，student 的概率权重和 log-prob 均保留梯度：

$$
\ell_{\rm full}(\theta;s)
=\sum_{a\in V}p_\theta(a\mid s)\left[\log p_\theta(a\mid s)-\log q(a\mid s)\right].
$$

5. 在块内取得 student hidden/head梯度，释放词表临时量，累计全局有效token均值的梯度，最后执行一次optimizer更新。不能每个词表块单独归一化或单独更新参数。

完整 logits 梯度为

$$
\frac{\partial\ell_{\rm full}}{\partial z_{s,a}}
=p_\theta(a\mid s)\left[\log p_\theta(a\mid s)-\log q(a\mid s)-D_s(\theta)\right].
$$

此处不需要当前位置的原生成 action 作为监督标签，也不需要额外训练 action、old log-prob 或 PPO ratio。原 token 仍通过历史、EOS 和有效位置影响哪些 state 进入训练。重新前向后，直接 KL 在每个参数点都是当前条件目标的真实梯度，不依赖冻结 reward 仅在锚点处等价的限制。

不能把负 KL 标量当作停止梯度的 reward，再乘某一个 rollout token 的 log-prob：固定 state 时该标量与 action 无关，在 student action 分布下 score 期望为零，不能实现上述完整梯度。

## 算法与执行成本对照

| 方式                  | 条件动作处理              | 条件梯度                          | 跨阶段监督的典型规模                     | 同 microbatch 融合执行所需逻辑前向   |
| --------------------- | ------------------------- | --------------------------------- | ---------------------------------------- | ---------------------------------- |
| sampled token 重新采样 | 从当前 student 取一个 action | 在当前锚点无偏，有采样噪声        | IDs 及 log-prob/系数 O(N)                   | 1 次 teacher 无梯度＋1 次 student 带梯度 |
| 只取 top-k 头部 score    | 枚举 K 个候选、遗漏尾部     | 一般有偏                          | IDs 及候选证据 O(NK)                       | 同上                               |
| top-k＋无偏 tail       | 枚举 K 个候选并采尾部贡献   | 在当前锚点无偏；方差取决于分布    | O(NK) 加尾部 action 证据                    | 同上                               |
| full-vocab 直接 KL      | 精确求和全部动作          | 对固定 state 精确，无 action 采样噪声 | teacher hidden O(NH_t)，共享 head O(VH_t) | 同上                               |

表中 O(N)/O(NK) 指已完成相应评分后可传递的监督，不表示 teacher 和 student 能在任何 worker 布局下无需额外中间表示地得到它们。在“teacher 先提供 hidden、student 一次带梯度前向”的融合布局中，sampled/top-k 也可暂存 teacher hidden 后再选择训练 action/候选。相反，现有分阶段 score-surrogate 布局通常先执行 student 无梯度评分，再 teacher 评分，再 student 带梯度更新，即 2 次 student＋1 次 teacher。减少一次 student 评分是执行布局优化，不是 full-vocab 独有的数学性质。激活 checkpoint 和词表重算的内部重执行不计入表中的逻辑前向次数。

当前常规输出头实现中，sampled 与 top-k 仍计算完整词表归一化；一个归一化 log-prob 的梯度也会经 softmax 影响整个词表，不能把其计算量简单视为 full-vocab 的 1/V 或 K/V。full-vocab 增加分布比较与归约，减少 action 噪声；分块主要限制同时存活的词表张量，未消除全部词表投影。具体显存、GEMM、通信和前向次数的影响见[性能说明](2026-10-19-完整词表蒸馏优化与四卡实测.md#显存与速度分别由什么决定)。

## 实现约束

- 三种方式共享 tokenizer 语义、有效词表、目标温度、原始 prefix、EOS/padding mask 与全局有效 token 归约；否则比较同时改变目标或状态权重。
- 学生采样分布必须与所声称的 p 一致。采样温度、top-p、top-k 截断和 repetition penalty 会改变实际行为分布。
- 头部 ID、系数和对应位置必须一致；跨更新复用冻结 surrogate 不能冒充当前 KL 的精确梯度。完整 KL 可以复用冻结 teacher 缓存，但 student 分布须刷新。
- teacher 参数始终冻结；student hidden 梯度必须传播回 backbone。完整词表 loss 只求一次有效位置均值，不能再除以词表大小。
- 性能比较分别记录 teacher 前向、student 前向/反向、head/KL、数据搬运、梯度同步与 optimizer；端到端另加 rollout 和权重发布。

本文只补全算法与语义说明，不宣称 sampled/top-k 新数据流已经通过原生训练验收。
