# OPD 访问测度研究导读

更新时间：2026-10-18。这组文档研究 OPD 如何在不同 prefix 上学习、怎样判断分布对齐，以及局部训练为何可能伴随重复退化。本文保留结论与阅读路线；完整假设、定理、证明、论文设置和运行命令分别归下面的专题。

## 核心判断

- 对齐主指标是独立题目上、当前 student rollout 对应的完整 sequence reverse KL；同时报告 token 平均、长度和共同固定 prefix 读数。相同协议下，小 sequence KL 保证 accuracy 接近 teacher，但不保证任务分数单调提高。
- 局部 OPD 对固定 prefix 的条件 KL 梯度可以无偏，但一般遗漏未来状态信用。Token-mean、未来 return-to-go 和 action 估计器是不同选择。
- 独立 logits、完整支持和理想优化下，不同来源可以收敛到同一 teacher；共享参数、有限覆盖和受限目标则可能产生不同投影或稳定点。
- 重复区域内的低 KL 不代表进入该区域的概率已对齐。TIDE 改变局部监督和部分目标，不能用其准确率改善证明原始完整 KL 已收敛。

这些结论的条件与证明归各专题。论文实证、数学推断与待检验机制分别标明；公式回归和短训练验收不作为 LLM 收敛证据。

## 三条阅读路线

1. **先决定指标：** 对齐指标 → 双向实验运行。需要理解优化曲线时再读局部梯度。
2. **研究重复机制：** 局部梯度 → 重复退化与 TIDE → 采样估计器 → State 诊断。
3. **研究来源与收敛：** 对齐指标 → 访问测度与六种 rollout → State 诊断 → 双向实验运行。
